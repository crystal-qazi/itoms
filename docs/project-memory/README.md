# ITOMS Project Memory

This directory is the version-controlled project memory for ITOMS.

## Source of truth
- Repository: https://github.com/crystal-qazi/itoms
- Default branch: `main`
- Primary memory: [PROJECT_MEMORY.md](./PROJECT_MEMORY.md)
- Operating protocol: [MEMORY_POLICY.md](./MEMORY_POLICY.md)

## How to use this memory
Before any ITOMS task, review the current files in this directory and any linked requirements, architecture, decision, skill, and implementation documents. After the task, update the relevant records and commit/push the changes.

## Record quality
Every entry must be labelled as one of:
- **Confirmed** — explicitly selected or approved by the user.
- **In progress** — work started but not completed/verified.
- **Pending** — agreed work not yet completed.
- **Open** — requires a decision or evidence.
- **Historical** — superseded, retained for traceability.

Do not convert assumptions into requirements. Preserve decision numbers and option numbers whenever known.
