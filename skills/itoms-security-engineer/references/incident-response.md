# ITOMS Security Incident Response Quick Guide

## Triggers
Suspected account takeover, privilege escalation, exposed credentials, malware upload, unauthorized document access, exfiltration, audit tampering, compromised integration secret, suspicious backup access or production exploitation.

## Workflow
1. Escalate promptly to the authorized hospital security/IT owner.
2. Preserve logs, audit records, timestamps, hashes and affected artifacts.
3. Contain safely: revoke sessions/credentials, disable integration, quarantine files or isolate service only with authorized operational coordination.
4. Assess accounts, data classifications, systems, time window, modules and evidence gaps.
5. Eradicate root cause and rotate affected secrets/keys using approved procedures.
6. Recover from known-good state; verify integrity and monitor recurrence.
7. Document timeline, decisions, impact, remediation and lessons learned.

Do not independently contact employees, vendors, regulators or external parties. Do not destroy forensic evidence during cleanup.
