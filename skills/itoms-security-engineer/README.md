# ITOMS Security Engineer Skill

Version 1.0.0. Project-specific security engineering standard for the primary AI development agent and compatible coding agents.

References: security architecture, threat modelling, secure coding, security testing, incident response. Templates: threat model and security assessment report.

Standards baseline: OWASP ASVS 5.0.0 Level 2, OWASP Top 10:2025, OWASP Cheat Sheet Series, NIST SSDF SP 800-218 v1.1, NIST CSF 2.0 and CIS Controls v8.1 where applicable. This is an engineering baseline, not certification or legal compliance. Verify current versions and vendor guidance when applying.
