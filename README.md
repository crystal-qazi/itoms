# ITOMS — IT Operations Management System

Private, offline-first hospital intranet system for managing IT operations across eight teams.

## Project status
- Requirements planning: finalized.
- Repository baseline inspection: started.
- Implementation: foundation phase.

## Technology baseline
- Python + Flask
- MySQL using parameterized native SQL (no SQLAlchemy ORM)
- Flask/Jinja2, Bootstrap and modular JavaScript
- Modular monolith; no Docker, microservices, React, Vue or Tailwind
- Private/offline-first intranet

Never commit credentials, secrets, production data or virtual-environment files. Apply ITOMS UI/UX Engineer, Full-Stack Engineer and Security Engineer standards throughout implementation.
